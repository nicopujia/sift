What changed in each release

Open a release to see its changes and the steps to upgrade.

Release 2.10
  • New: the export command writes CSV and JSON.
  • Fixed: a crash when the config file is empty.
  • To upgrade, run toolkit update and restart the service.
Python 3.12

Python 3.12 is supported from release 2.8. Older releases need Python 3.10 or 3.11.

Release 2.9 (beta)

Beta only: the new scheduler, off by default.
