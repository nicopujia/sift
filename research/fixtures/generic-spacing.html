class pathlib.PurePath(*pathsegments)

A generic class that represents the system's path flavour. Instantiating it creates either a PurePosixPath or a PureWindowsPath.

>>> PurePath('setup.py')
PurePosixPath('setup.py')

Each element of pathsegments can be either a string representing a path segment, or an object implementing the os.PathLike interface.
