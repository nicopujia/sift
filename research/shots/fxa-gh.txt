  p: Preact is a fast, lightweight React alternative with a modern API, components, and a Virtual DOM.
  H2 Preact
  p: Preact is a fast 4 kB alternative to React with the same modern API. It offers Virtual DOM components with less overhead.
    li: Familiar React API and patterns, including ES6 classes, hooks, and functional components
    li: React compatibility through the preact/compat alias
    li: JSX, VDOM, DevTools, HMR, and SSR
    li: Optimized diffing and seamless hydration from server-rendered pages
    li: Support for all modern browsers
    li: Transparent asynchronous rendering with a pluggable scheduler
  p: You can find more information on the Preact website. Preact has an npm package and a Slack community. The project lists Coveralls, gzip size, and Drydock review. See the awesome-preact list for libraries.
  H2 Getting Started
  p: You don’t need ES2015 to use Preact, but you can try it.
  H2 Tutorial: Building UI with Preact
  p: Build user interfaces by combining components and elements into trees. Components are functions or classes that describe what their tree should display. Write these descriptions in JSX or HTM, which uses JavaScript tagge
  p: Use render() to create a structure from a tree description and append it to a parent DOM element. Later calls reuse the existing tree and update it in place. Preact compares the old and new structures to minimize DOM ope
  p: The second call updates the <h1> text with one DOM call.
  p: For more complex applications, components divide the interface into nested parts. Each component can compare changes from its own mounted point.
