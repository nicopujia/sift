  p: Preact is a fast, lightweight alternative to React with a similar modern API.
  H3 Preact
  p: Preact is a 4kB alternative to React. It offers Virtual DOM components with less overhead:
    li: Familiar React APIs and patterns, including ES6 classes, hooks, and function components.
    li: React compatibility through the `preact/compat` alias.
    li: JSX, VDOM, DevTools, HMR, and SSR.
    li: An optimized diff algorithm and seamless hydration from server-side rendering.
    li: Support for all modern browsers.
    li: Asynchronous rendering with a pluggable scheduler.
  p: The project lists its website, npm package, Slack community, Coveralls, gzip size, and Drydock review. Find more libraries in the awesome-preact list.
  H3 Getting Started
  p: You do not need ES2015 to use Preact, but you can try it.
  H4 Tutorial: Building UI with Preact
  p: Build user interfaces from trees of components and elements. Components are functions or classes that describe their output. Write these descriptions in JSX or HTM, which uses JavaScript tagged templates. Both can repres
  p: Use `render()` to create a tree and append it to a parent DOM element. Later calls reuse and update the existing tree in place. Preact compares the old and new output to reduce DOM operations.
  p: ```js import { h, render } from 'preact'; // Tells Babel to use h for JSX. Configure this globally if possible. // See https://babeljs.io/docs/en/babel-plugin-transform-react-jsx#usage // In tsconfig, set this with jsxFa
  p: render( <main> <h1>Hello</h1> </main>, document.body );
  p: render( <main> <h1>Hello World!</h1> </main>, document.body ); // The second call updates the h1 text with one DOM call. ```
  p: Components help manage changes as an application grows. Nested components can each compare changes from their mounted point, instead of comparing the whole application.
